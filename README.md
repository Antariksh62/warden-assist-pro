# Hostel Command

You are a Senior Product Designer and Principal Frontend Engineer who previously designed enterprise software for Microsoft, Atlassian, ServiceNow, SAP, Linear, Vercel and Datadog.

Your task is NOT to build an application.

Your task is ONLY to design the frontend UI/UX for an Enterprise Hostel Operations Intelligence & Decision Support System (HOIDSS).

The target audience is NOT students.

The target audience is the Hostel Incharge (Chief Warden / Operations Head) who manages the entire hostel infrastructure.

The dashboard should feel like a modern enterprise SaaS product rather than a college project.

Think:

• Microsoft Power BI

• Linear

• Vercel

• Atlassian

• Datadog

• Notion

• ServiceNow

DO NOT make it colorful or playful.

It should look professional enough that a university director could present it during a board meeting.

====================================================

IMPORTANT

DO NOT generate backend code.

DO NOT generate APIs.

DO NOT generate authentication.

DO NOT generate database models.

DO NOT generate routing.

DO NOT generate business logic.

DO NOT create mock backend architecture.

DO NOT redesign any other pages.

ONLY DESIGN THE FRONTEND OF THE HOSTEL INCHARGE DASHBOARD.

====================================================

The dashboard should answer ONE question:

"What decisions should management make today?"

NOT

"How many complaints exist?"

Every widget should help management take action.
